Raw data are not redistributed here. To rebuild `data/derived/` with
`python data/prepare_data.py`, download into this folder:

- `pennycook2019/`: Pennycook & Rand (2019), *PNAS*, OSF https://osf.io/6bptd/
- `lin2023/`: Lin et al. (2023), *PNAS Nexus*, https://github.com/hauselin/domain-quality-ratings
- `robertson2018/`: Robertson et al. (2018), *PACM HCI*, partisan audience bias scores
